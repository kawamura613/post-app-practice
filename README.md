# チームチャットアプリケーション (完成版)

Laravel + MySQL + Laravel Sail を用いて構築された、コンポーネント指向のチームチャットアプリケーションです。
画面・ロジック・テスト・設計ドキュメントにいたるまで、すべての成果物が一貫性を持って美しくクローズされた完成状態のリポジトリです。なお、本アプリケーションのフロントエンド（画面UI）は**JavaScriptを1行も使用せず**、Laravel標準の機能とCSSのみで堅牢に構築されています。

---

## 1. できること
設計書の機能一覧に基づき、ブラウザ上の直感的なUI（リンクとボタンのみ）で以下のすべてを網羅して体験できます。
- **ユーザー認証:** Fortifyをベースにしたセキュアなサインイン・サインアウト
- **チャンネル管理:** 公開/プライベートチャンネルの作成、およびメンバーの招待・脱退モーダル操作
- **メッセージ / スレッド投稿:** 1,000文字制限のリアルタイム追随、編集、論理削除（跡地表示への切り替え）
- **リアルタイム風スレッド返信:** 親メッセージに紐づくサイドパネルでの返信一覧・投稿（削除済みを考慮した件数表示）
- **全文検索エンジン:** かな揺れ・大文字小文字・アクセントをci(照合順序)で吸収するハイライト付きGET検索、100文字抜粋の末尾境界処理
- **外部公開API:** 完全にセッションを排除した、ログイン不要の外部システム連携用読み取り専用エンドポイント

---

## 2. 動かす
以下の手順を順番に実行するだけで、あなたのローカル環境へ完全にシステムをクリーンに再現できます。

```bash
# ① リポジトリのクローン
git clone https://github.com/kawamura613/post-app-practice.git
cd post-app-practice

# ② 環境設定ファイルの準備
cp .env.example .env

# ③ 依存パッケージのインストール (Dockerコンテナ起動用の準備)
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    laravelsail/php82-composer:latest \
    composer install --ignore-platform-reqs

# ④ コンテナのバックグラウンド起動
./vendor/bin/sail up -d

# ⑤ アプリケーションキーの生成
./vendor/bin/sail artisan key:generate

# ⑥ データベースの初期化と初期データの積載 (必ず --seed を付与します)
./vendor/bin/sail artisan migrate:fresh --seed
```

## 4. ひととおり触ってみる (一周ルート)
数分間でアプリケーションの全機能を網羅して検証できる最適な道順です。

1. **佐藤 太郎でサインイン:** http://localhost を開き、`sato@example.com` でログイン。
2. **チャンネル確認:** サイドバーに「# 全体連絡」「# 開発」「# 雑談」に加え、鍵アイコンの「🔒 採用プロジェクト」が見えることを確認。
3. **メッセージと返信:** 「雑談」チャンネルで新規投稿を行い、そのメッセージの「返信」を押して右パネル（スレッド）から返信を投稿。
4. **検索と着地:** 上部バーの検索窓にキーワード（例: `リリース`）を入れてEnter。検索結果に表示されたメッセージ行をクリックし、元のチャンネルの該当位置へ背景色ハイライト付きでジャンプ（着地）することを確認。
5. **高橋 健で入り直す (隠蔽の検証):** 一度ログアウトし、今度は未参加である `takahashi@example.com` でログイン。
6. **防衛の確認:** サイドバーから「🔒 採用プロジェクト」が完全に消えていることを確認。さらに、ブラウザのURLへ直接 `/channels/4`（採用プロジェクトのID）や `/api/channels/4/messages` を直打ちしても、クラス名などの痕跡を漏らさずクリーンな **404 (見つかりません)** になる防衛挙動を確認。

## 5. 公開API
ログインセッションを持たない社内ポータル等の外部システム向けに、読み取り専用（GET）のAPIが2本提供されています。

| メソッド | エンドポイント | 応答内容と仕様 |
| :--- | :--- | :--- |
| **`GET`** | `/api/channels` | 全ての**公開チャンネルのみ**をJSON一覧で返却（プライベートは完全除外・totalカウントに入りません）。 |
| **`GET`** | `/api/channels/{channel}/messages` | 指定された公開チャンネル内のメッセージ一覧をcreated_at降順で返却。削除済みメッセージの本文は自動除外され、`reply_count` は削除された返信をカウントしないよう自動補正されます。 |

### 💡 curl での確認例
```bash
curl -X GET http://localhost/api/channels -H "Accept: application/json"
```
※ APIは1分間に60回（IPごと）の利用回数制限があり、超過時は429（Too Many Requests）のクリーンなJSONを返します。GET以外の不正なアクセスは405で弾かれます。

## 6. テストと整形
すべてのコードは自動テストによる品質担保と、自動整形によるルール遵守が徹底されています。

### 自動テストの実行
```bash
./vendor/bin/sail artisan test
```
- **通過時出力:** `Tests: 163 passed (944 assertions)` が出力され、`failed` が 0 件であることを確認。
- **バグ片付け:** 素のLaravel初期見本テスト（`tests/Unit/ExampleTest.php`）は不整合防止のため安全に削除され、`phpunit.xml` もクリーンアップ済みです。

### 自動整形の検証
```bash
./vendor/bin/sail pint --test
```
- **通過時出力:** `{"tool":"pint","result":"passed"}` (違反コード 0 件、ルール完全遵守)

├── docs/

├── routes/

└── tests/
    └── Feature/                    # 7つの実装単位それぞれに対応する、162件の結合テスト群
