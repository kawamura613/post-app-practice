#### UC-05: 入った注文を確認する

- **アクター**: 店員
- **事前条件**: カウンターの中のタブレットに入った注文が表示されていること
- **基本フロー**:
    1. 店員がタブレットで新しく入った注文の内容（商品と個数）を確認する。
    2. 店員が商品を作り、来店したお客さまに商品を手渡す。
    3. 店員がその場でタブレットの「渡しました」ボタンを押す。
    4. システムが該当の注文を「お渡し済み」として記録し、未対応の一覧から非表示にする。
- **代替フロー**:
    - なし
- **事後条件**: 商品の受け渡しが完了したことがシステムに記録され、渡し忘れが防止されていること
- **受け入れ条件**:
    - 注文に対して「渡しました」と記録ボタンを押すと、その注文が未対応一覧から消える。
