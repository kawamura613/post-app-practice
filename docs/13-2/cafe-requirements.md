#### UC-01: {商品を注文し支払いをする}

- **アクター**: {お客さま}
- **事前条件**: {「なし」}
- **基本フロー**:
    1. お客さまが商品を選択する
    2. お客様が商品の個数を選択する
    3. システムが合計を計算する
    4. お客さまが支払いをする
- **代替フロー**:
    - 4a.支払い時にエラーが出たらエラーメッセージが出る
- **事後条件**:支払いが済むと商品が登録され注文番号が表示される
- **受け入れ条件**:
    - [ ] 商品と個数を選択すると合計金額が表示される
    - [ ] 支払いが済むと注文番号が表示される
