# 機能一覧

| ID   | 機能                                               | 主な利用者 |
| :--- | :------------------------------------------------- | :--------- |
| F-01 | ドリンクとフードの一覧を表示する                   | お客さま   |
| F-02 | 商品と個数を選んでアプリの中で支払いを済ませる     | お客さま   |
| F-03 | 注文がお店に届いているかをアプリで確認する         | お客さま   |
| F-04 | 注文の取り消し（キャンセル）をする                 | お客さま   |
| F-05 | タブレットで入った注文を見られるようにする         | 店員       |
| F-06 | 商品をお客さまに渡した際、「渡しました」と記録する | 店員       |
